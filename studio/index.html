How this works

The live site reads catalog_admin.json at page load and applies card order, covers and galleries. Publishing uploads that file plus any new photos — a ~10 KB commit, live in about a minute, no page rebuild. Product renames/prices still live in SITE_GROUPS.json (the builder), which is what “Rebuild + publish” regenerates.
